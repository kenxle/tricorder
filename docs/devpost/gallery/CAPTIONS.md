# Devpost gallery captions

- 01_start.png: Tricorder opens on one question. Paste a company's website and the research starts.
- 02_first_readout.png: The first readout: what the company does, then What stands out, each point read from public sources only.
- 03_evidence.png: Every point carries numbered evidence. Hover a number to see the fact and its source.
- 04_data_room_request.png: The data-room request is a dialog over the working page. It lists what to ask for, with a draft email the associate sends from their own mail.
- 05_request_sent.png: Once the request goes out, every item shows as open with the time it was asked. The founder's data room arrives as a notification.
- 06_room_partly_in.png: The first files arrive and the working page updates. A red flag from the room leads, with a question to put to the founder.
- 07_room_in_full.png: With the whole room in, Tricorder has read every file. Green and red flags lead, each with the stated figure beside what the room shows.
- 08_flag_drilled_down.png: One piece drilled down: each line from the room with its sources, which ones agree and which disagree, and the figures side by side.
- 09_steering.png: The associate steers the readout in a plain sentence. Here a steer asks for more: it goes onto the data-room request and waits on the founder. A steer never changes a check's own number.
- 10_memo.png: The associate's memo is a document about the company, with the evidence behind each number a click away.
- 11_partner_review.png: The partner reads the memo and asks questions in a chat. Answers come from the memo and link to the paragraph.
