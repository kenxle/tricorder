# Font sources

Fetched on 2026-10-24 from the Fontsource packages on jsDelivr, pinned to exact versions: `@fontsource/archivo@5.2.8` and `@fontsource/ibm-plex-mono@5.2.7`. Fontsource repackages the Google Fonts releases. Both fonts are under the SIL Open Font License 1.1; each licence file sits beside its fonts.

Only the Latin subset is vendored, and only the weights the style guide uses: Archivo 400, 500, 600, 700 and 800, and IBM Plex Mono 400 and 500. Archivo is the normal-width cut (OS/2 width class 5). No wide or expanded cut is included.
