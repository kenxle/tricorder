06 What it addsBeside similar tools

Similar tools link a memo to its sources. Tricorder adds this.

  1. L.01The best green flags and the worst red flags first, then an overview of every piece of the company, strong and weak.
  2. L.02Sources shown both ways: the files that agree on a number as well as the ones that disagree.
  3. L.03Numbers checked by scripts, not by a model's reading, and verdicts set by a stated rule.
  4. L.04Contract terms read against how each contract is counted.
  5. L.05Gaps written as gaps, and an ask list for the founder.
  6. L.06An interactive memo each partner can steer and run what-ifs on.
  7. L.07Checks beyond the room: the pitch video, comps and the associate's usual tabs.
