One strip per piece of the company

Each piece gets one mark, set by a stated rule. A mark describes one piece. It is never a call on the deal.

  • Looking strongAt least one corroborated number, nothing contradicted.
  • Looking weakA flag, or contradictions and nothing corroborated.
  • MixedCorroborated and contradicted numbers, and no flag.
  • Not enough in the roomNo number has a second source, either way.

03Among similar tools

What Tricorder adds.

Several tools already turn a data room into a memo with linked sources, and one fund partner built his own. That validates the idea. Here is what Tricorder adds to it.

  1. 01The best green flags and the worst red flags first, then an overview of every piece of the company, strong and weak.
  2. 02Sources shown both ways: the files that agree on a number as well as the ones that disagree.
  3. 03Numbers checked by scripts, not by a model's reading, and verdicts set by a stated rule.
  4. 04Contract terms read against how each contract is counted.
  5. 05Gaps written as gaps, and an ask list for the founder.
  6. 06An interactive memo each partner can steer and run what-ifs on.
  7. 07Checks beyond the room: the pitch video, comps and the associate's usual tabs.
04Where it stops

What it is not.

  • Not a sourcing database or a CRM.
  • Not confirmatory diligence. It is the first pass, before a second meeting.
  • Not a replacement for the partner's judgment. It never says invest or pass. It reads out what it found, and the partner decides.

Where the data goes

Tricorder reads only the documents you give it or the decks in mail you send it, keeps only the readout and its sources, and lets you see and delete everything it pulled.
