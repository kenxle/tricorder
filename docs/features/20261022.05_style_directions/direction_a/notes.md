# Direction A: Reference Range

- **Name:** Reference Range. Every number sits against its range, the way a vital sign sits against its normal band; a red flag is the out-of-range mark.
- **From the motif:** the range strip under each flag and disagreement (track, accent band, ticks, red out-of-range triangle); the triangle as the "looking weak" mark; the overview drawn as monitor channel rows; the lab report's source, value and reference columns in the tables; a faint chart-paper grid behind the hero and call to action only.
- **Rule behind the band:** the band means sources agree within 1% (the room's green-flag rule) or a check rebuilt the figure. A disagreement gets no band, so the strip never picks a winner.
- **Risk taken:** the strip is a new chart type on every flag. It makes the readout denser and asks the reader to learn one convention. Strip labels round ($2.24M) while the table underneath keeps exact dollars.
- **Unsure:** Atkinson Hyperlegible draws a slashed zero, so dollar figures in sentences look slightly technical; worth Ken's eye. Hollis Voice has no "mixed" or "not enough in the room" piece, so those two verdict lines show the BRAND template with brackets. Verdict counts stay [n] because they come from a run. The overview's marks for market, team and the pitch itself come from the room's README and answer key, not from a Tricorder run. Comps is shown as "running".
- **Build:** both pages were joined from shared sources in the session scratchpad (base.css, a token table generated from the CSS so the guide's hex cannot drift). The HTML files here are the complete, standalone output.
