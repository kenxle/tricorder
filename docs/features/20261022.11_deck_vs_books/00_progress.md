## How to rerun the spike

From `docs/features/20261022.11_deck_vs_books/spike/`, with pdfplumber, openpyxl, pypdf and Pillow, and matplotlib for the test decks (`pip install -r data_room/requirements.txt`):

```sh
python3 make_test_decks.py ../../../../data_room/hollis_voice out/test_decks
python3 deck_vs_books_spike.py ../../../../data_room/hollis_voice --out out/hollis_voice.json
python3 deck_vs_books_spike.py ../../../../data_room/hollis_voice --deck out/test_decks/chart_starts_late.pdf --out out/hollis_voice_chart_starts_late.json
python3 deck_vs_books_spike.py ../../../../data_room/hollis_voice --hide 02_financials/financial_model.xlsx --out out/hollis_voice_no_pnl.json
python3 deck_vs_books_spike.py ../../../../data_room/brasswick --out out/brasswick.json
python3 validate_against_skeleton.py <folder with the skeleton's schema, scans, eval and a data_room link> ../../../../data_room/brasswick out/brasswick.json
python3 render_interface_example.py
```
