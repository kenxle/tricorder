 How to manage fundraising data rooms
 Fund managers can seamlessly run the entire fundraising process in one place on Carta, including setting up data rooms to facilitate secure document sharing.
 The fundraising data room has the following features:
 - Integration with fundraising and subscription document experience

- Easy control of access for GPs

- Tracking documents viewed and visits to data room by user

- Watermarking documents

- Ability to require NDA signing
