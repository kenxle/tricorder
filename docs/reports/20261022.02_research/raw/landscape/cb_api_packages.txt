# Overview
Learn more about the available Crunchbase API Packages
Crunchbase offers three main API packages — **Fundamentals, Insights, and Predictions** — delivering real-time private market data directly to your products, models, or tools. The data from these packages can be valuable for use cases like lead targeting and qualification, private market growth and risk assessments, investment strategy and proactive portfolio management, and data-powered product builds.
Use the Crunchbase API to enrich internal systems, power custom workflows or models, or embed data into external applications at scale. Insights and Predictions are always bundled with Fundamentals. Insights adds analyses of past and present private market activity, while Predictions adds forward-looking intelligence. Explore the packages below to find the best fit for your needs.
## Find your API reference
Use the reference that matches the package provisioned to your API key. Insights and Predictions always include Fundamentals; the available endpoints and fields depend on your Crunchbase license.
| Data offering | API reference package |
| --------------------------------------------- | ----------------------------------------------------------------------------------------- |
| Fundamentals: Core and Advanced Firmographics | [Firmographics Package](https://data.crunchbase.com/reference/getorganization) |
| Fundamentals: Core Financials | [Core Financials Package](https://data.crunchbase.com/reference/getorganization-1) |
| Fundamentals: Advanced Financials | [Advanced Financials Package](https://data.crunchbase.com/reference/getorganization-2) |
| Fundamentals with Insights | [Insights Only Package](https://data.crunchbase.com/reference/getorganization-4) |
| Fundamentals with Predictions | [Predictions Only Package](https://data.crunchbase.com/reference/getorganization-5) |
| Fundamentals with Insights and Predictions | [Predictions & Insights Package](https://data.crunchbase.com/reference/getorganization-3) |
“Insights Only” and “Predictions Only” are technical reference labels that distinguish those variants from the combined “Predictions & Insights” reference. **They do not mean Fundamentals are excluded.**
# Fundamentals Data
## *Historical firmographic and financial data*
> The Fundamentals Data Package provides the core building blocks of Crunchbase’s best-in-class private company data — spanning millions of company profiles, milestones, financial history, and market trends. License the full Fundamentals Package for the most extensive detail on private companies, or choose from the following:
>
> * **Core Firmographics**: Essential company data — including name, type, legal status, employee count, and key leadership — to verify businesses and enrich workflows.
> * **Advanced Firmographics**: Deeper context on private company ownership, organization structures, accelerators, diversity, education, and public activity for sharper segmentation and prioritization.
> * **Core Financials**: A company financial snapshot — including funding stages, aggregate and latest funding information, and investor details — to spot opportunities faster and make confident decisions. For round-by-round funding histories, consult the [Advanced Financials reference](https://data.crunchbase.com/reference/getfundinground); available endpoints and fields depend on your provisioned package.
