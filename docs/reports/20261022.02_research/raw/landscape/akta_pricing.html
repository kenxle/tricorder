Each API consumes a set number of credits per call; the sections below break down credit consumption by API type. ## Cost per credit and rate limits The cost per credit and rate limit depend on your plan: | Plans | Pay as you go | Subscription | Enterprise | | - | - | - | - | | Cost per credit | \$0.05 | \$0.04 | Custom | ## News Signals | API | Credits Consumed | | :- | :- | | News Signals | 0.1 per API call, 0.01 per news article | ## Company Data Company Data is priced per section, so you only pay for the sections you request. Funding Detail and M\&A and Investment are available only on subscription tier (limited access) and enterprise tier (complete access). | Section | Credits Consumed | | :- | :- | | Firmographic | 2 | | Business Model | 2 | | Company Assessment | 2 | | Trust Signal | 0.5 | | Company Hierarchy | 0.5 | | Digital Presence | 0.5 | | Financial Estimate | 0.5 | | Location | 0.5 | | Management Profile | 1 | | Product Offering | 2 | | Strategic Signal | 1.5 | | Customer Profile | 1 | | Industry | 1 | | Technology | 2 | | Funding Detail *(subscription, enterprise)* | 3 | | M\&A and Investment *(subscription, enterprise)* | 5 | ## List Generation List Generation credit consumption is made up of a base cost, an additional cost if using natural language `query` instead of structured `filters`, a per-company cost, and an optional per-section enrichment cost. Section costs are the same as those listed in the Company Data table above. | Component | Credits Consumed | | :- | :- | | Base cost per API call | 1.5 | | Additional cost if using `query` instead of `filters` | 2.5 | | Per company returned | 0.2 | | Per enrichment section requested | (Section cost, per Company Data table above) × companies returned | **Formula:** ```text theme={null} Total credits = 1.5 + (2.5 if using `query`, else 0) + (0.2 × companies returned) + (sum of each requested section's cost × companies returned) ``` **Example:** A `filters`-based request returning 50 companies, with `firmographic` (2 credits) and `location` (0.5 credits) sections requested: ```text theme={null} 1.5 (base) + 0 (filters, not query) + (0.2 × 50) + ((2 + 0.5) × 50) = 1.5 + 0 + 10 + 125 = 136.5 credits ``` > [!NOTE] > > **Filter Builder API** — 2.5 credits per run. Rather than passing natural language directly to List Generation's `query` parameter, you can call the [Filter Builder API](/api-reference/supporting-apis/filter-builder) first to convert it into a structured `filters` object. This costs the same 2.5 credits as the `query` surcharge, but gives you a reviewable, reusable filter set you can inspect, tweak, or cache before running (and re-running) List Generation with `filters` instead. ## Alternative Signals | API | Credits Consumed | | :- | :- | | Headcount Trends | 2.5 | | Web Traffic | 1.5 | | Job Posting | 4 credits for 10 records | | Social Posts | 1 credit for 10 records | | Employee Reviews | 1.5 credits for 50 records | | Product Reviews | 1.5 credits for 50 records, 0.5 credits when called without products | ## Guidelines and notes * Top-up credits are valid for 12 months from the date of purchase. * Monthly plan credits expire at the end of each billing cycle and do not roll over. * Credits are non-transferable between accounts and non-redeemable for cash.
