Documentation

Build on Nicrron.

One OpenAI-compatible endpoint for chat, embeddings, audio, image and video models. If you already use the OpenAI SDK, you change the base URL and the key.

cURL — your first request
curl https://api.nicrron.ai/v1/chat/completions \
  -H "Authorization: Bearer $NICRRON_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "nicrron/auto",
    "messages": [{ "role": "user", "content": "Hello!" }]
  }'
