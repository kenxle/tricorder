Legacy Basic API documentation
Crunchbase no longer offers new Basic API keys. This page describes legacy Basic access for existing key holders. See Crunchbase Basic for availability details. For a current API package or a newly provisioned key, follow Using the API and the reference for your provisioned package; do not apply these legacy paths to a new key.
With Crunchbase Basic, you have access to a limited set of Organization data fields (as covered in Organization Attributes) using the 3 API endpoints below:
Organization Search endpoint: https://api.crunchbase.com/api/v4/searches/organizations
Organization Entity Lookup endpoint: https://api.crunchbase.com/api/v4/entities/organizations/{permalink}
Autocomplete endpoint: https://api.crunchbase.com/api/v4/autocompletes
🚧
Access depends on your API package
Legacy Basic keys have limited access. For current offerings, review API Packages and contact Crunchbase to confirm the endpoints and fields included in your provisioned package.
