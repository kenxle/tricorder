Welcome to Crunchbase Data
Connect with MCP or build with the REST API.
Bring Crunchbase company, funding, people, Insights, and Predictions data into your work. Choose MCP to work through an AI assistant, or use the REST API to retrieve data directly in your applications and pipelines.
Choose how to connect
Use Crunchbase in your AI tools with MCP
Connect your AI assistant to Crunchbase to research companies, explore funding activity, and build lists through natural-language requests.
Start here: Getting Started with MCP.
Choose your client: Connecting AI Tools.
Access: Sign in with your Crunchbase account. Individual access requires an MCP seat assigned by your workspace admin. See Managing MCP Access, or contact your account team if your workspace does not have MCP.
Building an application using MCP? See Building a Crunchbase MCP Integration and contact your account team about application access.
Explore the MCP overview →
Build applications and data pipelines with the REST API
Make HTTP requests to search collections, look up entities and relationships, and retrieve data for enrichment, analysis, and your own integrations.
Start here: Make your first API request using your existing key in the interactive reference. See Using the API for authentication, rate limits, and retries.
Understand the data: Learn how entities, fields, and cards fit together.
Find an endpoint: API Reference.
Follow a workflow: API Starter Playbooks.
Access: You need a provisioned REST API key. See API access and key retrieval.
MCP seat access and REST API access are different access arrangements. An MCP seat does not replace the API key required for REST requests, and a REST API key is not the sign-in method for an individual MCP connection.
Explore Crunchbase data
Fundamentals: Company profiles, people, relationships, and financial records.
Insights: Analyses and signals that help explain company and market activity.
Predictions: Forecasts of outcomes such as funding, acquisition, IPO, growth, layoffs, closure, and remaining private.
For REST API package details and available reference definitions, see API Packages Overview. Use the Data Dictionary to explore API and CSV fields. For data exposed through MCP tools, see the MCP Overview and Developer Reference.
