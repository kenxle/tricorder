# Writing guidance

Use the vendored [technical-writing](../vendor/pstack/skills/technical-writing/SKILL.md)
and [unslop](../vendor/pstack/skills/unslop/SKILL.md) guidance when writing or
reviewing prose. Preserve the consuming project's voice, document components,
and author choices. Read the source that applies rather than adding a writing
review chain or reloading both documents for every small edit.

For skill work, follow the host provider's established authoring skill when
available, such as skill-creator or create-skill. Resolve tool names through the
host's actual capabilities. This package does not depend on one provider's
authoring tool.
