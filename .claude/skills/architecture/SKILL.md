# Architecture

Read the PRD, or the detailed brief for the full dossier route, and relevant code
before design. Use the [templates](../feature-forge/references/templates.md).
Preserve reconnaissance, affected components, data/state contracts, flows,
failures, trust boundaries, and meaningful alternatives with rationale. Name the
domain's data shapes before logic. Reference requirements and the Plan table
instead of duplicating them. Choose architecture/security perspectives by need
and resolve contradictions. Plan follows. No external architect skill is required.
